## ✂️ What's inside

| Page | What it does |
| --- | --- |
| 🏠 **Home** | 3D barber pole hero, shop story, featured services, reviews, hours and map |
| 💷 **Services & Prices** | Full price table for cuts, beards, shaves and products |
| 👥 **Meet the Team** | The barbers and their specialities |
| 🖼️ **Gallery** | Masonry grid with a keyboard-friendly lightbox |
| 📅 **Book Now** | Booking form with time slots based on opening hours |
| 📍 **Contact** | Address, phone, hours and accessibility info |

## ⚓ Highlights

- Mobile-first, with a sticky **Book Now** button on every page
- Accessible: semantic HTML, alt text, keyboard navigation, reduced-motion support
- No frameworks or build step, just plain HTML, CSS and JS
- LocalBusiness schema and per-page SEO tags

## 🚀 Run it locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.
